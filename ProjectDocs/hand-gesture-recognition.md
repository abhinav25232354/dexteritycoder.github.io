# Hand Gesture Recognition Documentation

## About the Project

This project uses MediaPipe and OpenCV to detect hand landmarks in real-time from your webcam, then maps those gestures to system-level controls!

## Requirements

- Python 3.8+
- A webcam

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abhinav25232354/Hand-Gesture-Recognition---Major-Project-2026-BCA-.git
   cd Hand-Gesture-Recognition---Major-Project-2026-BCA-
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## How to Use

1. Run the main script:
   ```bash
   python main.py
   ```
2. Allow webcam access when prompted
3. Make gestures in front of the camera!

## Supported Gestures

- ✊ Fist - Pause/Play media
- ☝️ Index finger up - Volume up
- 👇 Index finger down - Volume down
- ✌️ Peace sign - Next track
- 🤟 Pinky + thumb - Previous track
